## 3. 功能说明

### 3.1 对比入口

批量结果表格操作列由「查看 | 明细 | 脱敏文件」调整为「**查看 | 对比 | 明细 | 脱敏文件**」：

- 「对比」为 `link type="primary"` 主操作，仅在 `row.taskId && row.status === "done"` 时可用；任务尚未完成时禁用并给出 title 提示。
- 查看 / 明细 / 脱敏文件 的绑定逻辑、顺序与原行为完全一致。
- 单文件检测与文本检测不出现「对比」入口（这两类任务不创建服务端快照，见 §5 限制），避免必然失败的入口。

### 3.2 对比工作台

- 大尺寸弹窗：宽度 88%（视口，窄屏 96%）、高度约 89.8% 视口；`top=4vh`、`append-to-body`、`destroy-on-close`、点击遮罩不关闭、Escape 关闭、内部独立滚动，主页面不位移。
- 顶部信息区：文档名、`已脱敏` 状态标签、「规则命中 N 次 · M 个片段 · K 字符」、视图切换、关闭按钮。
- 工具栏：同步滚动开关（默认开）、自动换行开关、`上一处 / 共 M 处差异（第 N 处） / 下一处`、`下载脱敏文档`。
- 文本阅读：行号（sticky 固定在左侧）、等宽字体、保留段落/缩进/换行、长文档滚动、长行横向滚动、自动换行切换；文本不溢出容器。
- 字符级差异高亮：原文敏感片段浅红（`rgba(214,69,69,.15)`），脱敏替换片段浅蓝（`rgba(74,135,228,.18)`），选中态加深；正常文本不高亮。
- 双栏联动：同步滚动默认开启；两侧行数不同时优先按差异映射锚点做分段线性同步，而不是简单滚动百分比；点击一侧高亮，另一侧对应片段同步高亮并滚入视野（双向）；上一处/下一处循环定位；字段浮层展示敏感类别、检测级别、替换策略、处理状态、文档片段路径。
- 视图切换：左右对比（默认）/仅原文/仅脱敏；窗口 resize 与 ≤980px 窄屏自动降级单栏，窄屏视图选项只保留「原文 / 脱敏文档」。
- 下载：直接调用 `saveBlob` 的对比下载接口，内容由服务端同一快照重建，界面展示与下载文件逐字一致（自动化测试断言）。
- 状态处理：加载中、无差异、无片段、404 任务不存在、403 无权限、409 脱敏副本失效、410 快照过期（含 5 分钟说明）、413 文档过大、网络错误兜底；错误显示后端 `error_id`，支持「重试 / 关闭」。
- 性能：不换行模式按视口 ±10 行做绝对定位虚拟滚动；滚动同步 rAF 节流；不重复渲染整份文档；未引入新依赖。
- 可访问性：`role="region"` + `aria-label` 标注两侧文档区、差异计数 `aria-live="polite"`、关闭按钮/字段浮层 `aria-label`、Element Plus 焦点圈定、Escape 关闭。

### 3.3 与原有视觉的兼容

- 弹窗沿用全局 `.el-dialog` 玻璃白底、24px 圆角、轻阴影；工作台内部为浅蓝 `#f8fbff` 面板、浅灰蓝行号列 `#eef4fd`、蓝色主按钮（`--el-color-primary #5b96ed`）。
- 未使用深色编辑器皮肤、渐变光效、额外动画；新增样式全部以 `dc-` 前缀隔离，未改动全局样式与 Element Plus 覆盖规则。

## 4. 数据流与安全机制

### 4.1 数据流

```
批量上传 POST /api/v1/tasks/batch（浏览器会话 Cookie）
  └─ create_task(comparison_owner = fingerprint(session cookie + Authorization),
                 comparison_secret = settings.export_secret)
       └─ 后台 _execute：检测 → 每个 finding 计算 finding.masked = protected_text(...)
            └─ snapshot_store.put('task:'+task_id, document, report, options,
                                  owner, secret, ttl=300s)   ← 仅内存、不落盘
GET /api/v1/tasks/{id}/comparison（同一会话 Cookie）
  └─ 校验 owner → comparison_payload：
       · 校验 segment.text 指纹 == finding.original_hash
       · 重新计算 masked 并校验 == finding.masked（不一致 → 409）
       · 返回 segments[{path, original, masked, changes[]}]
         changes: {start,end,masked_start,masked_end,type,strategy,level,status}
         offset_unit = "unicode-codepoint"
GET /api/v1/tasks/{id}/comparison/download
  └─ 同一 payload → '\n'.join(segments[].masked) 纯文本附件
前端 DocumentCompareDialog：
  comparison payload → codepoint→UTF-16 偏移映射 → 行模型 → 字符级 <mark> 渲染/虚拟滚动
```

- 原文与脱敏结果来自**同一任务快照**；快照保存的是解析后的 document/report/options，按任务 ID 与 owner 绑定，TTL 300 秒，重启失效。
- 前端不做任何脱敏计算，只做偏移换算、分行、渲染与交互；高亮区间完全来自后端 `changes`，不做字符串搜索定位。

### 4.2 安全控制（均为交付包既有能力，本次接入并验证）

| 风险 | 控制 |
| --- | --- |
| 未授权读取原文 | 快照 owner = 浏览器会话 Cookie（`flowmask_detection_session`，HttpOnly/SameSite=strict）+ Authorization 指纹；`secrets.compare_digest` 校验，匿名/跨会话返回 403 `SNAPSHOT_FORBIDDEN` |
| 浏览器缓存原文 | 对比与下载响应均 `Cache-Control: no-store` + `Pragma: no-cache`；前端不写 localStorage/sessionStorage/IndexedDB，不 `console.log` 原文 |
| 前端伪造脱敏结果 | 界面只展示服务端 `masked` 与 `changes`；下载同样走服务端 payload，同一快照重建 |
| 快照过期/策略变化 | 410 `SNAPSHOT_EXPIRED`、409 `SNAPSHOT_POLICY_CHANGED`/`MASK_LOCATION_INVALID`，前端显示可操作错误态 |
| 文档过大 | 对比内容上限 1,000,000 字符 → 413 `COMPARISON_TOO_LARGE`；快照总预算 32 MB / 32 条 |
| 关闭后残留 | `destroy-on-close` 销毁弹窗 DOM，`@closed` 清空 payload 引用、高亮、浮层与滚动状态；下载使用 objectURL 后立即 revoke |
| 降低脱敏策略 | 未改后端脱敏/快照/安全代码；对比只是读取既有结果，不提供任何绕过入口 |

## 6. 尚未实现 / 受现有接口限制的功能

以下均为**交付包既有后端能力边界**，本次未越权修改后端，前端已给出对应提示或规避：

1. **仅批量任务支持对比**：`POST /tasks/batch` 才创建服务端快照；单文件 `POST /tasks` 与 `POST /tasks/text` 的 `/comparison`、`/comparison/download` 返回 410。前端因此只在批量结果中提供「对比」，若快照过期则在弹窗内提示重新检测。
2. **快照 TTL 300 秒、进程重启失效**：这是后端 `SnapshotStore` 的既有设计（`max_items=32`、`max_bytes=32MB`，单进程内存）。页面停留过久后对比会显示「对比快照已过期」，需重新检测。
3. **对比内容上限 1,000,000 字符**：超过时任务可正常完成、脱敏文件可正常导出，但 `/comparison` 返回 413；前端显示「文档过大」并保留关闭/重试。
4. **命中数与差异数语义不同**：`comparison.hits` 含敏感词（`kw-`）命中，可能大于实际 `changes` 数；界面已分开显示「规则命中 N 次」（含 title 说明）与「共 M 处差异」。
5. **对比只呈现解析后的文本片段**（`representation=parsed-segments`）：PDF/图片 OCR 文档以解析文本呈现，不还原原文档版式、表格线框与分页。
6. **前端文本渲染细节**：默认固定行高 22px；超过 20 万字符时禁用自动换行（仅横向滚动），避免超长行换行测量开销；行高与字号未提供用户自定义。
7. **413 上传错误响应缺少 `no-store`**：后端后台上传/检测的 413 响应头缺少 no-store/Pragma（无数据泄露，属既有轻微不一致），本次按「不改无关后端」原则未修改，仅记录。
8. **未新增依赖、未使用深色编辑器**：未引入 Monaco/CodeMirror 等大型编辑器依赖，全部用轻量 DOM + Vue 渲染实现。
9. **便携 zip 未重新打包**：本次只更新了解压目录 `FlowMask\web\dist` 与源码/测试，未重建 `FlowMask-0.27.2-全功能版-Portable.zip`、未更新 `SHA256SUMS.txt`；如需重新分发，请按原 `打包说明.md` 重新打包并更新校验和。
