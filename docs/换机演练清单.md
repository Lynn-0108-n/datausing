# 换机演练清单（干净环境预演）

> 目的：验证「把仓库拷到一台干净 Windows 机器」后，按文档能否从零跑起来。
> 本文记录 **2026-10-22 本机干净环境预演**的实测过程、数字、发现并修复的缺陷，以及真机复跑时要勾的项。
>
> 预演环境：Windows + Windows PowerShell **5.1.26100.9444**（`powershell` 命令；本机无 PowerShell 7），
> Python **3.12**（`C:\Users\31387\AppData\Local\Programs\Python\Python312`），
> 干净 venv 位于 `%TEMP%\flowmask-clean`，`server/data` 置空、未构建前端 `web/dist` 移走、未下载额外权重。
> 预演对象是 Python 一体机（`server/`，含 BFF + Vue 前端），不涉及 Go 采集端单机部署。

## 2. 本轮发现并修复的交付缺陷

预演最大的价值是把「本机开发能跑、换机就炸」的问题提前暴露。本轮共修复 5 类：

1. **4 个 `.ps1` 丢失 UTF-8 BOM**（回归）：`server/scripts/start_local.ps1`、`server/scripts/stop_local.ps1`、
   `deploy/upload-netmon.ps1`、`deploy/windows/start-local-analysis.ps1`。
   PowerShell 5.1 在无 BOM 时按 ANSI 解码中文，直接报 `Unexpected token '}'` / `The string is missing the terminator`，
   **README 的 Windows 一键入口在干净机器上完全不可用**（本机即复现）。已补回 BOM。
2. **`.cmd` 包装含 UTF-8 中文注释**：`start_local.cmd`、`stop_local.cmd` 的 `rem` 中文被 cmd.exe 按 OEM 代码页
   （中文系统 CP936）误解码，启动时打印 `'庯細Windows' 不是内部或外部命令` 等多余错误。已改为纯 ASCII 注释。
3. **`.cmd` 包装吞掉子进程退出码**：`start_local.cmd` / `stop_local.cmd` / `demo.cmd` 以 `endlocal` 结尾，
   即使 PowerShell 脚本失败也返回 0；`stop_flowmask.cmd` 的 fallback 同样恒返回 0。
   现已统一 `set "RC=%ERRORLEVEL%"` + `endlocal & exit /b %RC%`，失败可被脚本/CI 捕获。
4. **`demo.ps1` 动态脱敏文案过时**：服务端授权改造后，客户端自报 `authorized=true` 不会再拿到原文，
   但演示仍打印「授权视图…返回原文」。现改为按 `policy` 分支断言：未授权视图必须不含原文；
   若 `policy=masked` 明确提示「客户端自报未获服务端授权，需把操作人加入 `FLOWMASK_REVEAL_OPERATORS` 白名单」；
   `policy=full_access` 时才校验返回原文。
5. **缺静态回归**：`server/tests/test_assets.py` 新增 4 例——非 ASCII `.ps1` 必须有 BOM；`.cmd` 包装必须纯 ASCII；
   `.cmd` 必须透出子进程退出码；`demo.ps1` 必须按服务端授权语义输出。防止以后编辑脚本再次把问题带回来。

## 3. 新机复跑清单（逐项勾）

前置：Windows 10/11 + Python 3.12（勾选 Add to PATH）；能访问内网镜像或互联网。

- [ ] `python --version` 为 3.12.x
- [ ] 拿到仓库（`git clone` 或解压压缩包），`cd server`
- [ ] 建虚拟环境：`python -m venv .venv`，`.venv\Scripts\activate`
- [ ] 装依赖（国内建议镜像）：
      `python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt`
- [ ] （可选，启用 L2/L3/NER 才需要）下载权重：`python scripts/download_models.py --list` 先看清单，
      `--only l3 ner`（约 3.3GB）或 `--all`（约 6.4GB）；仅 L1 可跳过
- [ ] 启动：`scripts\start_local.cmd -NoBrowser`（默认 8090；被占用加 `-Port 8095`）
- [ ] 打开 `http://127.0.0.1:8090/ui/`（未构建前端）或 `/app/`（已构建）；`/api/v1/health` 返回 200
- [ ] 冒烟：`scripts\demo.cmd`（默认 8090），8 项应全 `[OK]` 且退出码 0
- [ ] 停止：`scripts\stop_local.cmd`，确认端口释放、进程退出
- [ ] 记录：机器配置、Python 版本、启动耗时、demo 结果、遇到的报错 → 回填本文

## 4. 待办 / 未覆盖项

1. **真机复跑**：本次只是同一台机器的干净 venv + 空目录预演，仍需一台真正的干净机（不同 Windows 版本/无开发环境）复跑并回填。
2. **权重下载未演练**：`download_models.py` 只验证了 `--list`（无需第三方依赖）；真实下载 6.4GB、镜像/代理、
   模型目录迁移未验证；L2/L3/NER 开启后的显存/首帧耗时属另一份《性能报告》范畴。
3. **前端构建未演练**：未构建时 `/ui/` 可用（已验证），`/app/` 需要 `web/` 下装 pnpm 依赖并 `build`；
   注意 `web/dist` 被 `.gitignore` 忽略，新机默认没有正式前端。
4. **exe 分发未演练**：`server/dist_exe/FlowMask.exe` 仍是旧构建（用户暂缓重打包），本次不覆盖。
5. **中文控制台显示**：cmd 窗口若中文乱码，可 `chcp 65001` 或设 `PYTHONIOENCODING=utf-8`；功能不受影响。

## 5. 参考命令

```powershell
# 干净环境（本次预演）
$venv = Join-Path $env:TEMP 'flowmask-clean'
python -m venv $venv
& "$venv\Scripts\python.exe" -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r server\requirements.txt

cd server
$env:FLOWMASK_PYTHON = "$venv\Scripts\python.exe"   # 让一键脚本用干净 venv 的解释器
.\scripts\start_local.cmd -Port 18090 -NoBrowser
.\scripts\demo.cmd http://127.0.0.1:18090 -NoBrowser
.\scripts\stop_local.cmd
```
